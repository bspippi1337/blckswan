## BLCKSWAN APP

BLCKSWAN v1.2 er et offline Android-verktøy for kritisk tenkning, problemløsing og praktisk læring. Den opprinnelige 100-punktsmodellen er komprimert til 12 kjernegrep i fire moduler: `FRIHET + KUNNSKAP + TEST + REVISJON`.

- [Åpne BLCKSWAN app-nettsiden](https://bspippi1337.github.io/blckswan/app/)
- [Se nettstedskilden](app/)
