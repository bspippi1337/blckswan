# BLCKSWAN Art Guide

En interaktiv GitHub Pages-utstilling gjennom ASCII-kunst, commit-poesi og Git-meta-kunst fra `ungtb10d`-arkivet.

## Utstillingen inneholder

- ni kuraterte verk med norske beskrivelser og kommentarer
- fullskjermvisning, zoom, søk, filtre og tastaturnavigasjon
- skalerbare SVG-gjengivelser uten fast oppløsningsgrense
- eksport av hvert verk som 4096 px PNG direkte i nettleseren
- permanente lenker til originalfiler og commits
- markering av originalverk, itererte verk og mulig remiks
- redigering av norsk fødselsnummer og andre unødvendige personopplysninger

## GitHub Pages

Workflowen [BLCKSWAN Art Guide Pages](../.github/workflows/art-guide-pages.yml) pakker ut den selvstendige nettsiden og publiserer den via GitHub Pages.

Forventet adresse:

`https://bspippi1337.github.io/blckswan/`

Dersom Pages ikke tidligere har vært aktivert for repoet: åpne **Settings → Pages**, velg **GitHub Actions** som kilde, og kjør workflowen manuelt én gang.

## Kuratorisk prinsipp

Git-loggen behandles som gallerirom, commit-meldingen som flate, diffen som bevegelse og shell-prompten som signatur. Kildene beholdes urørt; utstillingen viser redigerte og kommenterte gjengivelser.
